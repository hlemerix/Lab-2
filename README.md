# Lab-2

Repositorio con los ejercicios del Laboratorio 2 de HTML5 y CSS3.

## Descripción general

Este proyecto reúne varias prácticas enfocadas en el uso de HTML5 semántico, estilos con CSS3, tablas, enlaces y validaciones de formularios.

## Archivos incluidos

- `ejemplo1.html`: ejemplo de uso de clases e IDs para dar estilo a una sección y a enlaces.
- `EjemploSecciones.html`: práctica con etiquetas semánticas de HTML5 como `header`, `nav`, `main`, `section`, `article`, `aside` y `footer`.
- `ValidacionesHTML5.html`: demo de validación de formularios con atributos HTML5 como `required`.
- `tablas.html`: tabla con diseño base aplicando estilos CSS.
- `tabla2.html`: práctica adicional de tablas con filas alternadas y estilos diferenciados.
- `parrafos.html`: archivo para practicar maquetación y estilos de texto.
- `estilosTabla.css`: hoja de estilos para tablas.
- `estilosParrafos.css`: estilos para párrafos y textos.
- `estilo,viaje.css`: archivo complementario con estilos para una tabla de viaje.

## Objetivos

- Comprender la estructura básica de una página HTML.
- Aplicar estilos con CSS3.
- Trabajar con selectores y clases.
- Crear tablas con presentación visual.
- Usar elementos semánticos de HTML5.
- Explorar validaciones nativas en formularios.

## Tecnología utilizada

- HTML5
- CSS3
- Navegador web moderno
- Visual Studio Code
- Git / GitHub

Abre cualquiera de los archivos `.html` en un navegador para ver cada ejercicio.
